# Player Guide (Founder Beta)

## Join a game

1. Open host URL from DM
2. Choose **Player**
3. Enter:
   - display name
   - Session ID
   - Player invite code

## Character/profile basics

Depending on enabled features and session settings, players can:

- maintain profile/character fields
- manage inventory/equipment
- use chat, dice, and player-side action controls

## Imports and character data

If DM has import flows enabled, follow their instructions for supported character data import.
When unavailable, manual profile + inventory entry still works.

## Linking a D&D Beyond character

Tavern supports linking a **publicly accessible** D&D Beyond character to your saved Tavern character profile.

1. Open your **Character Library** and choose **Link D&D Beyond**.
2. Paste the public D&D Beyond character URL or numeric character ID. Supported public profile-character URLs can also be used.
3. Review the imported character information and confirm the save.
4. Tavern saves its own playable copy of the character and remembers the D&D Beyond link.
5. Later, use **Refresh** on the linked character card to update supported source-derived fields from D&D Beyond.

A refresh is deliberately conservative. Source-derived character details can be updated, while Tavern live/campaign state such as current HP, temporary HP, spent spell slots, token placement and overrides, notes, and campaign-specific additions are kept where applicable. A refresh does not automatically heal a character.

If D&D Beyond is unavailable, times out, changes its response format, or the linked character becomes private, Tavern keeps the last successfully saved character available for play. Make the D&D Beyond character public again before retrying a failed refresh.

Use **Open source** to open the linked public D&D Beyond character. Use **Unlink** if you no longer want Tavern to refresh from D&D Beyond. Unlinking removes only the sync relationship: it does not delete the Tavern character, linked token, already imported data, notes, or campaign state.

This is D&D Beyond character import/link support built around publicly available character access. It is not an official D&D Beyond API partnership. Tavern does not require or store your D&D Beyond password or login cookies and does not bypass private-character access controls.

## During play

- Move only tokens you control
- Use chat and dice tools
- Follow combat turn prompts from DM

## Reconnect flow

- If disconnected, reopen the same URL/session
- Use same account/name where possible
- Ask DM to confirm you rejoined

## Phone/tablet notes

- **Phone:** fine for joining, chat, dice, and lightweight sheet checks
- **Tablet:** better for longer sessions and inventory interactions
- **Desktop/laptop:** best overall for heavy interaction

## Founder-beta expectations

- Some features may be rough or evolving
- If anything seems stuck, refresh and rejoin first
- Report reproducible issues to your host/DM with steps
